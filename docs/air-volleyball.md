# 气排球记录（五人制）

核对日期：2026-10-20。

进入“比赛记录 → 计分”，选择“气排球记录（五人制）”。本机控制台创建比赛时也可选择该规则。

## 规则依据

- [中国企业体育协会：2026 年气排球赛事规程](https://www.cesa.org.cn/Htmlfolder/bmxx/Content_8321.shtml)：明确采用《气排球竞赛规则 2026–2029》及赛事特殊规定，五人制、三局两胜、21/21/15 分，每局领先两分、无封顶。
- [日本气排球协会公开规则说明](https://fiavb.com/jp/zh/what-is-air-volleyball)：每球得分后轮转发球、每局两次 30 秒暂停、六次换人。
- [该协会规则译编 PDF](https://assets.fiavb.com/jp/assets/qipaiqiu-rules-2026-2029.pdf)：4.1 登记运动员最多十人；8、10 节五人位置及轮转；16.1 换人不受位置限制；19.2 决胜局先到八分交换场区。该文件为协会依据旧版与新版修订条款编译的日文资料，并非中国排协中文原版。

## 对应行为

| 内容 | 气排球记录 |
| --- | --- |
| 场上人数 | 五人；前排 IV、III、II，后排 V、I |
| 名单 | 每队 5–10 人，无自由人；CSV / XLSX 使用同一限制 |
| 局制 | 三局两胜；前两局 21 分，第三局 15 分；至少领先两分，无封顶 |
| 发球 | 首球按先发球队 I 位；此后每次得分，得分队顺时针轮转一位再发球 |
| 暂停 | 每队每局两次，每次 30 秒 |
| 换人 | 每队每局六人次；可替换任意场上位置，不套用六人制固定配对限制 |
| 决胜局 | 重新确认先发球队；领先队到八分时记录交换场区，保持轮次 |
| 表格 | 五列轮次、双方名单、发球轮次得分、暂停、换人、判罚、局分；不显示自由人控制表 |
| 备份 | 沿用 JSON 格式，保存并恢复气排球规则、五人阵容与完整比赛记录 |

记录表是基于现有电子记录流程适配的五人版，打印与 PDF 共用该结构，并非官方纸质表格的逐像素复刻。

地方赛事可能另行规定名单人数、混合队男女比例、换人次数或封顶分。本选项实现上表规则；暂不提供这些特殊规定的自定义设置。场上击球、触网等由裁判判定，系统记录裁判给出的得分与判罚。技术统计仍保留独立的 B6 表。

npm run build
npm run build:offline

浏览器流程需要先启动 `npm run dev`；离线检查需先生成离线文件。浏览器流程覆盖规则切换、名单、五人位置、连续得分与轮转、撤销、换人上限、暂停、延长局、决胜局交换场区、赛后确认、JSON 恢复及打印。
