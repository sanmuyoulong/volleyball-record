# Volley Record

一套基于 FIVB 纸质记录表工作流的排球电子记分原型。它把赛前名单、位置轮次、发球轮转、得分划记、暂停、换人、局间交接和比赛汇总放在同一条流程中。

项目维护、规则实现、测试、部署、已知限制和后续路线详见 [项目交接文档](HANDOFF.md)。

## 运行

```powershell
npm run dev
```

浏览器打开 `http://127.0.0.1:4173/`。页面会自动保存在浏览器本机存储中。

## 测试

```powershell
npm test
npm run test:advanced
node scripts/visual-test-chrome.mjs sample-page.png
npm run test:pdf
```

规则测试覆盖普通局、三局两胜/五局三胜决胜局、比赛结束、发球轮转和轮次表校验。视觉流程会检查样例载入、加分与撤销、暂停、换人、局结束后的下一局轮次提示，以及下一局计分栏中的历史局比分。

## 规则版本

- `FIVB 2025–2028 正式规则`：当前全球通用的正式室内排球规则，每队每局最多 6 次普通换人。
- `FIVB 2026 指定赛事试行`：适用于 VNL、U17 世锦赛和洲际锦标赛等指定赛事，每队每局试行 8 次普通换人。

两种规则共同使用基于项目内 `记录表.pdf` 和 `中文位置表.pdf` 设计的专业电子记录表样式，纸质表不再作为独立规则版本。

2026 年每局 8 次换人目前只用于 FIVB 指定测试赛事，不是全球通用正式规则；普通赛事应选择每局 6 次换人的 2025–2028 正式基线。

官方资料：

- <https://www.fivb.com/wp-content/uploads/2025/01/FIVB-Volleyball_Rules2025_2028-EN-v05.pdf>
- <https://www.fivb.com/fivb-board-of-administration-approves-rule-tests-for-2026-competitions/>

## 当前原型已实现

- 四步赛前信息向导与示例数据。
- 比赛信息中可选择三局两胜或五局三胜；决胜局分制、8 分换场和胜局判定自动同步。
- 首页直接选择正式规则或 2026 指定赛事试行规则。
- 得分、发球权和六轮轮转联动。
- 仅允许撤销最后一次正确得分的减分逻辑。
- 30 秒暂停倒计时与申请时比分记录。
- 普通换人的场上名单、自由人、配对回换与次数校验。
- 独立自由人控制：后排资格、完成回合间隔、对应常规球员换回、第二自由人切换和必须离场提醒。
- 不当请求、延误警告/判罚、行为警告、罚分、驱逐与取消比赛资格；判罚得分自动写入比分并以红圈标记。
- 完整操作审计：得分、暂停、换人、自由人、判罚和开新一局均保留操作前快照；纠错只能撤销最近有效操作并要求填写原因。
- 完整比赛 JSON 导出/导入，以及最近 5 个关键状态的自动恢复快照。
- 决胜局 8 分换场提示。
- 每局结束后的下一局位置轮次表。
- 计分栏持续展示此前各局比分。
- 记录表展示双方完整名单、号码、教练员姓名和所查看局的双方轮次表。
- 自动划分的纸质记录表视图、局结果与本机自动保存。
- “导出完整比赛 PDF”会生成比赛概览页，并按每局一页输出全部已创建记录表；浏览器中选择“另存为 PDF”即可保存。
- A4 横向分页打印样式与建议文件名。

## 后续正式部署建议

当前版本是可运行的前端原型。用于正式赛事前，建议继续加入登录权限、云端数据库、双设备实时同步、电子签字、判罚操作面板、自由人替换控制表和防误触审计日志。
