# Volley Record

一套基于 FIVB 纸质记录表工作流的排球电子记分原型。它把赛前名单、位置轮次、发球轮转、得分划记、暂停、换人、局间交接和比赛汇总放在同一条流程中。

项目维护、规则实现、测试、部署、已知限制和后续路线详见 [项目交接文档](HANDOFF.md)。

## 运行

```powershell
npm run dev
```

浏览器打开 `http://127.0.0.1:4173/` 查看平台首页；进入 `http://127.0.0.1:4173/record/` 后选择“计分”或“技术统计”。两种记录分别自动保存在浏览器本机存储中。

计分入口为 `/record/?mode=score`，沿用原有规则选择、赛前向导和比赛流程；已有比赛会恢复到上次记录的位置。技术统计入口为 `/record/?mode=statistics`，填写 B6 表的赛前信息与本队最多 14 名队员后进入统计表。控制台中的比赛链接可直接进入该场计分或某一队的技术统计。

## 本机控制台

访问 `/console/`，点击“进入本机控制台”使用演示身份。游客计分与统计仍无需进入控制台。这里没有真实账号、密码或云端同步，数据保存在当前浏览器的 IndexedDB；退出保留记录。网站与离线 HTML 通过完整备份迁移。

可以管理独立比赛、赛事、分组、队伍库和名单快照；每场比赛共享基础信息，分别保存计分、主队和客队技术统计。没有正式计分时使用共同手动比分，确认结束后计入积分榜；正式计分开始后优先引用计分，并等待赛后确认。多个标签页不会静默覆盖同一比赛的修改。

“另存到控制台”复制游客草稿为新比赛，保留原稿。旧赛事与比赛归档首次进入时迁移并保留原始备份。详细使用流程、存储边界、云端扩展接口和测试见 [控制台说明](docs/console.md)。

## 离线单文件

运行 `npm run build:offline` 生成 `output/Volley-Record-离线版.html`。将这一个文件复制到任意文件夹，用新版 Chrome 或 Edge 双击打开，无需服务器或网络，首页、计分、技术统计（含二传与分析报告）、名单导入和赛事管理均可使用。CSS、图标和全部程序内嵌，页面间跳转保持在同一文件。

记录保存在打开文件的浏览器中，独立于在线站点。已有比赛通过“数据管理”导出 JSON，再在离线版导入；HTML 本身不包含当前比赛数据。打印 / 导出 PDF 仍通过浏览器打印窗口操作。检查入口为 `npm run test:offline`，在断网环境中验证复制改名后的独立文件、页面切换、名单 CSV / XLSX、记录恢复与导出。

规则测试覆盖普通局、三局两胜/五局三胜决胜局、比赛结束、发球轮转和轮次表校验。视觉流程会检查样例载入、加分与撤销、暂停、换人、局结束后的下一局轮次提示，以及下一局计分栏中的历史局比分。

技术统计测试覆盖五组加减与总数、零值保护、名单校验、草稿与表格恢复、备份导入导出、手机横向滚动、A4 横向打印以及两种记录的数据隔离。名单导入测试另外覆盖 CSV / XLSX 预览与确认、模板下载、第一工作表读取、名单重排后保留统计以及错误名单不覆盖数据。

启用二传技术统计后，记录页可选择场上二传。此后原表的扣球加一自动归属所选二传，更换二传不会重置累计数据；减一撤回该队员、该结果最近一次记录，扣回原归属。展开当前二传进攻明细可查看队友表现。分析报告与 PDF 增加各二传在场时队友进攻的汇总及同一队员对比，效率 =（扣死 − 失误）÷ 总进攻次数，并列出扣死率和记录次数。二传本人进攻与独立二次进攻不计入队友效率；旧数据和未选二传时的扣球保留为未归属。

## 规则版本

- `FIVB 2025–2028 正式规则`：当前全球通用的正式室内排球规则，每队每局最多 6 次普通换人。
- `FIVB 2026 指定赛事试行`：适用于 VNL、U17 世锦赛和洲际锦标赛等指定赛事，每队每局试行 8 次普通换人。

两种规则共同使用基于项目内 `assets/记录表.pdf` 和 `assets/中文位置表.pdf` 设计的专业电子记录表样式，纸质表不再作为独立规则版本。

2026 年每局 8 次换人目前只用于 FIVB 指定测试赛事，不是全球通用正式规则；普通赛事应选择每局 6 次换人的 2025–2028 正式基线。

## 当前原型已实现

- 四步赛前信息向导与示例数据。
- 比赛信息中可选择三局两胜或五局三胜；决胜局分制、8 分换场和胜局判定自动同步。
- 独立平台首页与功能导航；比赛记录位于 `/record/`，提供计分和技术统计两种入口；控制台位于 `/console/`，用本机演示身份管理比赛、赛事和可复用队伍；旧 `/tournaments/` 链接兼容跳转。
- B6 联赛技术统计：比赛名称、场序、统计队名、主客队、性别、日期、城市、比赛馆、五局比分、比赛结果、胜队与签名信息；14 行队员与原表双层表头。
- 技术统计性别可选男子、女子或男女混合；混合比赛的名单逐人选择男／女，Excel / CSV 支持“性别”列，缺少时可导入后补填。记录表在姓名旁显示性别，保留原表 22 列，备份与打印同步保留。
- 赛前信息不再填写比赛结果。记录页通过“填写比分”更新每局比分和胜队，勾选“本局已结束”后计入总局分；进行中的比分允许持平，保存后同步进入表格、备份和打印。
- 赛前只填写比赛信息与队员名单；统计员和技术代表签名在记录页通过“填写签名”补填，保存后进入表格、备份与打印。
- 技术统计队员名单支持 Excel `.xlsx` / CSV 导入、预览与模板下载，可直接使用计分页的名单文件；至少包含“号码”和“姓名”，支持 1–14 名队员。文件中的队伍名称写入所选统计队伍；已有统计按号码和姓名保留，不能导入会丢失已有统计或替换队伍的名单。
- 发球（得分）、扣球（扣死）、一传（到位）、拦网（拦死）、防守（好球）均可按“成功 / 一般 / 失误”点击加减；队员总数和全队合计自动计算。总数为派生值，不提供单独加减；空白队员行的按钮禁用。
- 技术统计单独自动保存、JSON 备份导入导出及 A4 横向打印。游客保留一份当前技术统计草稿；控制台中的每场比赛按主客队分别保存。新建前可导出上一场备份；填写签名栏为文字记录。
- 技术统计新增“分析报告”预览。打印 / 导出 PDF 自动附带全队概览与队员明细：个人得分排名、五项技术成功项占比、失误率和次数分布。全队比例按汇总次数计算，同分并列；无记录项目显示“—”。常规 14 人名单输出三页：B6 原表、全队分析、队员明细与计算说明。
- 技术统计赛前页和记录页均可“载入样例比赛”，直接体验完整的男女混合名单、3∶1 比分、技术计数及分析报告。样例为演示数据；替换已有填写内容前需要确认，取消保留原记录，计分数据独立保存。
- 赛前可选启用二传技术统计，单独填写最多 4 名二传，也可从本队名单带入。到位球传球、调整球传球记录“失误 / 一般 / 到位”，二次进攻球记录“得分 / 一般 / 失误”，每项通过加减计数并自动汇总。分析报告增加二传专项页，包含原始计数、到位率、得分率和失误率；二次进攻独立记录，不自动写入原表或重复加入得分榜。启用时 PDF 共五页（含二传在场时进攻对比），未启用仍为原来的三页；取消启用保留二传数据以便恢复，旧备份默认关闭该功能。
- 比赛记分页可选择正式规则或 2026 指定赛事试行规则。
- 得分、发球权和六轮轮转联动。
- 仅允许撤销最后一次正确得分的减分逻辑。
- 30 秒暂停倒计时与申请时比分记录。
- 普通换人的场上名单、自由人、配对回换与次数校验。
- 独立自由人控制：后排资格、完成回合间隔、对应常规球员换回、第二自由人切换和必须离场提醒。
- 不当请求、延误警告/判罚、行为警告、罚分、驱逐与取消比赛资格；判罚得分自动写入比分并以红圈标记。
- 完整操作审计：得分、暂停、换人、自由人、判罚和开新一局均保留操作前快照；纠错只能撤销最近有效操作并要求填写原因。
- 完整比赛 JSON 导出/导入，以及最近 5 个关键状态的自动恢复快照。
- 决胜局 8 分换场提示。
- 每局结束后的下一局位置轮次表。
- 计分栏持续展示此前各局比分。
- 记录表展示双方完整名单、号码、教练员姓名和所查看局的双方轮次表。
- 自动划分的纸质记录表视图、局结果与本机自动保存。
- “导出完整比赛 PDF”会生成比赛概览页，并按每局一页输出全部已创建记录表；浏览器中选择“另存为 PDF”即可保存。
- A4 横向分页打印样式与建议文件名。
- 本机演示控制台：创建独立比赛或赛事下的对阵，队伍库和名单快照、主客队独立技术统计、正式计分统一比分、赛后确认积分榜、归档恢复、全量 JSON 备份及旧数据迁移。

## 后续正式部署建议

当前版本是可运行的前端原型。用于正式赛事前，建议继续加入登录权限、云端数据库、主记录设备与只读观众的实时同步、电子签字、服务端归档、监控告警和安全防护。
